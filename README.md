# Sudoku Solver

An interactive **Sudoku Solver** web application built using **HTML, CSS, and JavaScript**. Solve puzzles automatically, undo/redo moves, and play at multiple difficulty levels with a clean and user-friendly interface.

## Features
- Automatic Sudoku solving
- Undo and redo moves
- Multiple difficulty levels
- Clean and intuitive interface

## How to Use
1. Open `index.html` in your browser.
2. Enter a Sudoku puzzle or use a preset.
3. Click **Solve** to get the solution.
4. Use **Undo/Redo** to correct mistakes.
5. Select difficulty levels to practice different challenges.

## Tech Stack
- HTML
- CSS
- JavaScript
